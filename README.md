# LAB_sperimentazione_aerospaziale
This repository contains the project for "Laboratorio di Sperimentazione Aerospaziale" of Politecnico di Milano (2025), held by prof. Paolo Lunghi. The authors of this project are Simone Benassi, Omayma Aouani, Chiara Adduci, Federica Beccaria and Federico Fiori.
The files are in Italian.
The project focuses on a series of statics and dynamics measurements via strain gauges, and discusses the experimental approach and related issues.
The static measurements concern a hollow cylindrical bar subjected to a torsional moment, and are aimed at caracterizing the elastic modulus of the material.
The dynamic measurements are taken on an alluminium bar, clamped at one end and subjected to a bending force to the other end. These measurements are aimed to find the first two resonance frequencies of the bar, by experimentally caracterizing the frequency response of the bar.
